# Домашня робота №7. Task List зі styled-components

Копія [проєкту task-list-pv511](https://github.com/Skhmelyuk/task-list-pv511) на коміті `2a54ef5`. Стилі `App`, `Header`, `TaskForm`, `Counter`, `TodoList` і `TodoItem` описані через `styled-components` у файлах відповідних компонентів. У `src/index.css` є базове скидання та шрифт.

`TodoItem` отримує transient props `$priority`, `$isCompleted` і `$isOverdue`, щоб вибрати кольори, закреслення та контур. `Counter` передає `$percentage` для ширини смуги прогресу.

~~~sh
npm ci
npm run dev
npm run build
npm run lint
~~~

Потрібен Node.js 20.19+ або 22.12+.

Під час першого запуску застосунок показує три демозадачі. Форма додає нові завдання, чекбокс перемикає статус, а кнопка з кошиком видаляє вибраний рядок. Зміни зберігаються в `localStorage`. Лічильники та індикатор прогресу оновлюються разом зі списком.

Дедлайн задається календарною датою. Невиконане завдання стає простроченим із наступного дня за місцевим часом. Скріншоти станів, мобільної версії та порожнього списку є в папці `screenshots`.
