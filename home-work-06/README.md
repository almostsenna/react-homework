# Домашня робота №6. Стилізація Todo App

Розвиток проєкту з ДЗ №5. Кожен компонент має свій файл `*.module.css`. `clsx` поєднує класи пріоритету, виконання й прострочення у `TodoItem`.

~~~sh
npm ci
npm run dev
npm run build
npm run lint
~~~

Потрібен Node.js 20.19+ або 22.12+.

Дедлайн містить дату й час. Виконана задача не показує попередження про прострочення. Сортування і фільтр статусу впливають на список, а лічильник підраховує всі задачі. Записи з ДЗ №5 за тим самим ключем `todos` отримують звичайний пріоритет.

Скріншоти десктопної та мобільної версій є в папці `screenshots`.
