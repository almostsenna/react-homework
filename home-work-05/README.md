# Домашня робота №5. Todo List на React і TypeScript

Перенесення застосунку `project-todo-js` на React зі стилями стартового проєкту.

~~~sh
npm ci
npm run dev
npm run build
npm run lint
~~~

Потрібен Node.js 20.19+ або 22.12+.

`App` зчитує задачі з `localStorage` під час лінивої ініціалізації `useState`. Ефекти зберігають список під ключем `todos` та оновлюють заголовок вкладки. Лічильник обчислюється з масиву задач, а сортування працює з його копією. Кнопка сортування перемикає порядок від початкового до А–Я, Я–А й назад до початкового.

У папці `screenshots` є скріншоти інтерфейсу та вкладки Application → Local Storage.
