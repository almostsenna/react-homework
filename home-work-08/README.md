# Домашня робота №8. Завершення Task List

Проєкт продовжує домашню роботу №7 зі `styled-components` і реалізує завдання з `03_finishing_task_list_implementation.md`. Початкова компонентна структура походить із [task-list-pv511](https://github.com/Skhmelyuk/task-list-pv511).

## Запуск

Потрібен Node.js 20.19+ або 22.12+.

~~~sh
npm ci
npm run dev
~~~

Для перевірки використайте `npm run build` та `npm run lint`.

## Реалізація

| Частина | Поведінка |
| --- | --- |
| `App` | Ліниве зчитування задач, імутабельні додавання, виконання й видалення, автозбереження через `useEffect` |
| `TaskForm` | Введення через форму, перевірка щонайменше трьох символів після `trim()`, очищення форми, фокус через `useRef` під час відкриття та після додавання |
| `Counter` | Кнопки «Всього», «В процесі» та «Виконано» перемикають фільтр і показують статистику всього списку |
| `TodoList` | Масив для відображення обчислюється через `useMemo` у `App`, для порожнього фільтра є окреме повідомлення |
| `TodoItem` | Керований чекбокс, видалення, кольори пріоритетів, закреслення та визначення простроченості |
| Заголовок вкладки | Кількість невиконаних задач або повідомлення про виконання всіх справ |

Нове завдання з’являється першим. Після додавання активується фільтр «Всього», щоб нову задачу було видно одразу. Кнопки-фільтри підтримують Enter і пробіл та передають активний стан через `aria-pressed`.

Задачі зберігаються під ключем `tasks_pv511`. Якщо цього ключа ще немає, застосунок зчитує список із попереднього ключа ДЗ №7 `task-list-pv511:tasks`. Збережений порожній список залишається порожнім після перезавантаження. Фільтр спочатку встановлений на «Всього».

Дедлайн задається календарною датою. Невиконана задача стає простроченою наступного дня за місцевим часом. Поточний день оновлюється кожні 30 секунд і при поверненні у вікно. Завершена задача показує стан виконання.

Усі компонентні стилі описані через `styled-components`. У `src/index.css` залишилися скидання та базовий шрифт. Скріншоти інтерфейсу є в папці `screenshots`.
